# 청크별 실제 추출 파일럿 실행 방법

## 실행 코드와 기록
- `extract_probe.py`: 고정 추출 프롬프트 및 단일 입력 시험.
- `run_chunk_pilot.py`: corpus 표본 선택, 모델 tokenizer 분할, 조건별 추출, 체크포인트 저장.
- `compare_pilot.py`: 이름·관계 표현을 Unicode NFKC/소문자/공백으로 정규화한 후 집합 비교.
- `pilot_raw/manifest.json`: 표본 원문과 전체 청크, 원문 문자 offset, 토큰 offset, seed, 입력/프롬프트 해시.
- `pilot_raw/*_e*.json`: 개별 요청·응답·시간·오류. 기존 기록의 입력·설정을 검증한 후 완료한 호출만 건너뜀.
- `pilot_comparison.json`: 전체 비교 통계와 관계별 근거.

Python 표준 라이브러리만 사용하며 학습이나 외부 API 호출은 하지 않는다. 추출 요청은 로컬 llama-server로만 보낸다. 원문 다운로드에만 인터넷을 사용한다.

## 데이터
공식 corpus: https://raw.githubusercontent.com/GraphRAG-Bench/GraphRAG-Benchmark/main/Datasets/Corpus/novel.json
실험 시 내려받은 파일의 SHA256은 manifest에 저장되어 있다. 재현 시 파일 해시가 일치하는지 확인한다. 실제 선택된 두 원문 구간은 manifest에 보존되어 있다. corpus 이름이 Novel이라도 모든 항목을 현대적 의미의 소설로 가정하지 않는다.

## 서버 실행
`environment.json`에 모델 이름과 모델·실행기 해시가 있다. 개인 경로는 제외했다. 설치한 llama-server와 해당 GGUF 모델을 다음 옵션으로 실행한다.
`--host 127.0.0.1 --port 11439 --ctx-size 8192 --gpu-layers 99 --parallel 1 --alias qwen-extraction --no-webui`
이미 사용 중인 포트를 덮어쓰지 않는다.

## 실행 명령
```bash
python3 download_corpus.py --output /path/to/novel.json
python3 run_chunk_pilot.py --corpus /path/to/novel.json --out ../../runs/pilot
python3 compare_pilot.py --raw ../../runs/pilot --out ../../runs/pilot_comparison.json
```
명령은 `experiments/pilot`에서 실행한다. `compare_pilot.py`의 옵션을 생략하면 저장된 기존 결과를 재계산한다. 새 실행은 `runs` 아래에 보존하여 기존 결과를 덮어쓰지 않는다.

## 통제와 한계
- 두 문서의 각 1,024토큰 구간을 같은 원문 그대로 나누며 중복·누락 없이 복원되는지 확인했다.
- 128/256/512 × seed17, 추가 E256 × seed29. 총 36건. 실행 순서는 고정 seed로 섞었다.
- 토큰 piece가 원문 UTF-8과 완전히 일치하는지 확인하고, UTF-8 문자를 중간에서 끊지 않는다.
- JSON 출력 형식만 제한한다. 의미적 유효성은 자동 판정하지 않는다.
- 재실행 설정: max_tokens=4096, temperature=0.2, top_p=0.9, repeat_penalty=1.1. 중복 관계와 generic category node를 만들지 않도록 프롬프트를 보완했다. cache_prompt=false이며 응답 usage의 cache token 수도 기록한다.
- 단순 문자열 기준 고유 relation은 의미적으로 고유한 fact와 다르다. 표현과 별칭이 달라도 별개로 집계될 수 있다.
- 자동 근거 검사는 문자열 포함 여부다. 원문에 등장하는 단어를 잘못 연결한 관계도 이 검사를 통과할 수 있다.
- 이번 최소 파일럿에는 E128/E512 반복과 청크 경계 이동 대조군이 없다. 논문용 결론 전에 추가해야 한다.
- 문서 전체 gold, recall, 사람 간 판정 일치도는 아직 측정하지 않는다.

초기 중단 실행은 `pilot_raw_initial`에 별도 보존되어 있다. 최종 표는 `pilot_raw`만 사용한다. 재현 시 입력 모델과 실행기 버전이 달라지면 같은 seed라도 출력이 달라질 수 있다.
