# 실행 상태

실제 corpus 파일럿 완료. 공식 GraphRAG-Bench Novel을 다운로드하고 2문서의 각 1,024토큰을 128/256/512 크기로 나누어 추출했다. E256 seed 변경 대조군을 포함해 재실행 36건을 완료했다.

- 재실행 요청 시간 합계 약 18.7분. 초기 형식 점검·실패 실행·분석 시간 제외.
- JSON 파싱 실패 0건, 출력 잘림 0건.
- 근거 문자열/endpoint 등의 자동 오류가 있는 호출 17건. 의미적 정확도와 별도 지표.
- 원문 대조 진단 사례 12개를 기록했다. 독립적인 사람 주석이나 전체 precision 측정은 아니다.
- 초기 반복 생성 실패 기록은 pilot_raw_initial에 보존했다.
- 완료 후 작업용 로컬 추론 서버를 종료했다.
